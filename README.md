## About

你好，我是 Crossng。我主要写 Swift 和 Java，偶尔用 Python 做视觉相关的实验。

我喜欢做小而具体的东西：一个能长期放在菜单栏里的工具、一个边界清楚的服务，或者一个把想法验证出来的实验项目。
